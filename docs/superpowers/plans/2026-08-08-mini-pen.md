# mini-pen Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build a dark, CodePen-like HTML/CSS playground with CodeMirror editors, debounced Zustand state, live iframe preview, resizable panes, and GitHub Pages deploy via Actions.

**Architecture:** Vite React SPA. Zustand (`persist` → `localStorage` key `mini-pen`) owns `html`/`css` after a 150ms debounce from the editors. `buildPreviewDocument` builds an HTML string for `iframe.srcdoc` (`sandbox="allow-same-origin"`, no scripts). Layout uses nested `react-resizable-panels` groups.

**Tech Stack:** Vite, React, TypeScript, Tailwind CSS v4 (`@tailwindcss/vite`), Zustand, CodeMirror 6 (`@uiw/react-codemirror` + lang packages), `react-resizable-panels`, Vitest, GitHub Actions (`actions/deploy-pages`).

## Global Constraints

- Vite `base` must be `'/mini-pen/'` (repo name) for GitHub Pages asset paths.
- HTML + CSS only — no JavaScript editor or `allow-scripts` on the preview iframe.
- Persist key: `mini-pen` in `localStorage`.
- Debounce ~150ms **before** store updates (not a second debounce in Preview).
- Reset writes starter defaults immediately (bypass debounce); no confirm dialog.
- Dark UI only — no theme toggle.
- Unit tests for `buildPreviewDocument` and store `reset`; no E2E in MVP.
- App brand string: `mini-pen`.

- [ ] **Step 4: Implement store**

`src/store/penStore.ts`:

```ts
import { create } from 'zustand'
import { createJSONStorage, persist } from 'zustand/middleware'
import { DEFAULT_CSS, DEFAULT_HTML } from '../lib/defaults'

export type PenState = {
  html: string
  css: string
  setHtml: (html: string) => void
  setCss: (css: string) => void
  reset: () => void
}

export const usePenStore = create<PenState>()(
  persist(
    (set) => ({
      html: DEFAULT_HTML,
      css: DEFAULT_CSS,
      setHtml: (html) => set({ html }),
      setCss: (css) => set({ css }),
      reset: () => set({ html: DEFAULT_HTML, css: DEFAULT_CSS }),
    }),
    {
      name: 'mini-pen',
      storage: createJSONStorage(() => localStorage),
      partialize: (state) => ({ html: state.html, css: state.css }),
      onRehydrateStorage: () => (state, error) => {
        if (error) {
          console.warn('mini-pen: failed to rehydrate from localStorage', error)
        }
        return state
      },
    },
  ),
)
```

Note: if `onRehydrateStorage` typing complains, simplify to omit it and rely on default persist; `console.warn` on storage errors is optional for MVP — persist failing still leaves in-memory state.

- [ ] **Step 1: Implement debounce hook**

`src/hooks/useDebouncedCallback.ts`:

```ts
import { useEffect, useMemo, useRef } from 'react'

export function useDebouncedCallback<Args extends unknown[]>(
  callback: (...args: Args) => void,
  delayMs: number,
): (...args: Args) => void {
  const callbackRef = useRef(callback)
  const timeoutRef = useRef<ReturnType<typeof setTimeout> | null>(null)

  useEffect(() => {
    callbackRef.current = callback
  }, [callback])

  useEffect(() => {
    return () => {
      if (timeoutRef.current !== null) {
        clearTimeout(timeoutRef.current)
      }
    }
  }, [])

  return useMemo(
    () =>
      (...args: Args) => {
        if (timeoutRef.current !== null) {
          clearTimeout(timeoutRef.current)
        }
        timeoutRef.current = setTimeout(() => {
          callbackRef.current(...args)
        }, delayMs)
      },
    [delayMs],
  )
}
```

`src/components/EditorLayout.tsx`:

```tsx
import { useEffect, useState } from 'react'
import { Panel, PanelGroup, PanelResizeHandle } from 'react-resizable-panels'
import { useDebouncedCallback } from '../hooks/useDebouncedCallback'
import { usePenStore } from '../store/penStore'
import { CodeEditor } from './CodeEditor'
import { Preview } from './Preview'

const DEBOUNCE_MS = 150

export function EditorLayout() {
  const html = usePenStore((s) => s.html)
  const css = usePenStore((s) => s.css)
  const setHtml = usePenStore((s) => s.setHtml)
  const setCss = usePenStore((s) => s.setCss)

  const [localHtml, setLocalHtml] = useState(html)
  const [localCss, setLocalCss] = useState(css)

  useEffect(() => {
    setLocalHtml(html)
  }, [html])

  useEffect(() => {
    setLocalCss(css)
  }, [css])

  const debouncedSetHtml = useDebouncedCallback(setHtml, DEBOUNCE_MS)
  const debouncedSetCss = useDebouncedCallback(setCss, DEBOUNCE_MS)

  return (
    <PanelGroup direction="horizontal" className="min-h-0 flex-1">
      <Panel defaultSize={40} minSize={20}>
        <PanelGroup direction="vertical">
          <Panel defaultSize={50} minSize={15}>
            <CodeEditor
              id="html-editor"
              label="HTML"
              lang="html"
              value={localHtml}
              onChange={(value) => {
                setLocalHtml(value)
                debouncedSetHtml(value)
              }}
            />
          </Panel>
          <PanelResizeHandle className="h-1 bg-zinc-800 data-[resize-handle-active]:bg-sky-600" />
          <Panel defaultSize={50} minSize={15}>
            <CodeEditor
              id="css-editor"
              label="CSS"
              lang="css"
              value={localCss}
              onChange={(value) => {
                setLocalCss(value)
                debouncedSetCss(value)
              }}
            />
          </Panel>
        </PanelGroup>
      </Panel>
      <PanelResizeHandle className="w-1 bg-zinc-800 data-[resize-handle-active]:bg-sky-600" />
      <Panel defaultSize={60} minSize={25}>
        <Preview />
      </Panel>
    </PanelGroup>
  )
}
```
